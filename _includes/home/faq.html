Frequently asked questions

Quick answers to common treasurer concerns.

Can I import existing data?

Yes. CSV imports handle rosters, transactions, and past budgets.

Can multiple people access a team?

Yes. Team members can view data, while treasurers/admins can edit financial workflows.

How do team invites work if email is not configured yet?

Invites can be created now and stay pending until accepted. Email delivery can be enabled separately.

How do password reset emails work?

Users request reset instructions and receive an email with a secure reset link.

What can members view vs edit?

Members are read-only for financial operations. Treasurers/admins manage budget, roster, transactions, and history.

How do I submit feedback if I find a bug or have an idea?

Use the in-app Feedback button. Submissions include context and go to the admin feedback inbox.

Can we generate demo teams from real data without exposing personal information?

Yes. Admins can clone with anonymization options for roster and transactions.

Is data secure?

Yes. Role-based permissions and full audit history protect sensitive financial data.
